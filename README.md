# Destination Networks

A Minecraft 1.21.1 teleportation mod that adds colored teleporter blocks.

## Adapted from Jake Teleports

This mod builds upon the concepts introduced in Jake Teleports, enhancing the teleportation experience with non-sequential teleports, personal teleport networks, configurable teleporter behaviour, configurable teleporter limits, and an all-new user interface for selecting destinations.

If you have a world with Jake Teleports already installed, you can switch to Destination Networks without losing your existing teleportation blocks.
